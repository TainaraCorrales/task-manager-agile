# Task Manager Agile Project

## Descrição do Projeto
Este projeto simula o desenvolvimento de um sistema de gerenciamento de tarefas
utilizando metodologias ágeis. O sistema permite criar, visualizar, atualizar e
excluir tarefas, auxiliando equipes no acompanhamento do fluxo de trabalho.

## Escopo Inicial
O escopo inicial do projeto contempla:
- Cadastro de tarefas
- Listagem de tarefas
- Atualização de tarefas
- Exclusão de tarefas

## Metodologia Utilizada
Foi adotada a metodologia Kanban, utilizando o GitHub Projects para organização
das tarefas nas colunas: To Do, In Progress e Done.

## Tecnologias Utilizadas
- Python
- Flask
- PyTest
- GitHub Actions

## Como Executar o Projeto
1. Instale o Python
2. Execute o arquivo app.py
3. Acesse http://localhost:5000

## Mudança de Escopo
Durante o desenvolvimento, foi identificada a necessidade de adicionar prioridade
às tarefas, permitindo melhor organização das atividades críticas da equipe.
Essa mudança foi registrada no Kanban e implementada no sistema.
